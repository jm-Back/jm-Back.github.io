👩🏻‍💻 프로젝트 기간 : 4주

실물금 매입/매도 내역 기능을 중심으로 금 자산 비율,금 시세 변동을 시각화한 서비스입니다.

기획/DB 설계, 비즈니스 로직 고민, 프론트, 백엔드, 배포까지 혼자 진행했습니다.

➡️ 매입/매도 비즈니스 로직 설계:실물금 매입·매도 프로세스를 분석하고 자산 변동 및 정산 로직을 설계했습니다. 실물금 특성을 반영해 매입 건 단위로 매도 기능을 구현하도록 개선했습니다.

➡️ Java Spring Boot & JPA 경험: Spring Boot와 JPA를 활용해 REST API를 설계·개발하고, 데이터베이스 연동과 트랜잭션 관리를 효율적으로 처리했습니다.

➡️ 공공데이터 API 배치: 공공데이터 금 시세 API를 활용해 배치 시스템을 개발하고, 서버에 스케쥴링을 걸어 일 1회 자동으로 데이터를 수집했습니다.

➡️ React 활용: React로 직관적이고 반응형 UI를 구현하며, 단일 페이지 내 기능별 컴포넌트를 모듈화해 사용자에게 단순하고 직관적인 UI를 제공하는 동시에 재사용성과 유지보수를 고려한 구조로 설계했습니다. 핵심 기능인 매입/매도 내역 추가 기능은 페이지 이동처리 대신 모달을 적용했습니다.

➡️ AWS EC2 배포 경험: AWS EC2에 애플리케이션을 배포하고 운영했습니다.
